# ✨ Functional Login Page

A modern and responsive login/signup interface built with HTML, CSS, and JavaScript. This project showcases a polished user authentication layout with a smooth sliding panel effect and interactive form switching.

## 🌟 Features

- Elegant sign-in and sign-up layout
- Smooth animated panel transition
- Responsive design for different screen sizes
- Social login icon buttons
- Clean and modern UI styling

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

## 📁 Project Structure

- `index.html` — Page structure and form components
- `style.css` — Styling and responsive design
- `script.js` — Toggle interaction for login/register forms

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the project folder:
   ```bash
   cd functional-login-page
   ```
3. Open `index.html` in your browser to view the project.
